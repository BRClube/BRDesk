# BR Desk – Assistência 24h

Versão reduzida do BR Desk contendo apenas o módulo de **Assistência 24 horas**.

## Estrutura

- `index.html` – entrada do sistema (menu da Assistência 24h)
- `Assistencia24horas/assistencia24horas.html` – formulário de protocolo de abertura
- `Assistencia24horas/assistencia24horasIndex.html` – tipos de serviço (guincho, panes, chaveiro, borracheiro)
- `Assistencia24horas/cidades/` – listagem de cidades e regiões com contatos de prestadores
